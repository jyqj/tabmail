## 已有能力与页面矩阵

| 后端能力 | 员工页 `/mail` | 管理页 `/company` |
| --- | --- | --- |
| GET company：成员/公司/运行时能力 | 身份与运行时开关 | 启用和治理入口 |
| 员工 provision / PATCH / reinvite | 不暴露 | 按角色和生命周期限制操作 |
| grants / mailboxes | 精确读取和发件身份 | 分页分配/撤回，send 与 read 独立 |
| templates / preview / status | 仅已发布授权模板 | 草稿版本/预览/发布/退役 |
| mailbox detail / source / PATCH / DELETE | 正文/按需原文/已读/确认删除 | 不因管理员角色读取所有内容 |
| outbound / attempts / retry | 本人记录/分页/诊断/授权复核重试 | 不把全公司记录混入“我的” |
