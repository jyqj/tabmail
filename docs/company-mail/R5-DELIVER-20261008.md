### 真实登录竞争

新测试必须提供实际 PostgreSQL DSN，缺失时失败而非跳过。每个叶实际创建隔离数据库、迁移和 seed，通过真实账户读取屏障制造变化，随后调用真实 Login/Refresh handler。旧密码、冻结后重新启用、角色变更的基线不但 Login 返回 200，而且真实 Refresh 200；单独冻结场景 Refresh 为 401。删除用户的旧登录返回 500；插入被实际 PG 表锁暂停时，用户行未被锁住。这六个目标失败与三个正常/失败控制构成固定九叶。

实现将账户快照验证与 refresh token INSERT 放在同一 PostgreSQL 事务，并持有用户行 `FOR SHARE` 至提交。改密、状态、角色和删除的生产写入与其互斥。缺失或变化的认证状态在 cookie 和登录时间更新前返回通用 401；存储失败保留脱敏 500。证明对象不进入 JSON 或持久化副本，当前生产签发入口始终附带证明。
