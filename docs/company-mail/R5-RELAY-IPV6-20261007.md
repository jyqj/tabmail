# Relay IPv6 address construction — 2026-10-07

## Implementation item and boundary

This is one independently verifiable implementation item under **R5-P6-090**,
with cancellation coverage relevant to R5-P6-040. Source baseline:
`4065c4909c8f21a401a9a1af6370fa3f72670b99`.

The relay previously formatted its address as `host:port`. A configured bare
IPv6 host such as `::1` therefore became `::1:port`, which the TCP dialer rejects
before reaching SMTP. The production relay now uses `net.JoinHostPort` with
the configured decimal port. IPv4/hostname routing and the host supplied to
TLS/authentication retain their previous values.

The patch changes only relay address construction, adds an actual loopback
regression, and records this evidence. It does not complete the parent TODOs,
qualify public mail/DNS or PostgreSQL persistence, or alter TLS trust/policy.
Historical central progress remains **10/171 completed, 161 remaining**.

## Frozen regression and candidate

`TestR5RelayNumericHostConnectAndCancel` drives the exported relay adapter with
numeric IPv4 and IPv6 hosts. The peer verifies the actual EHLO, MAIL, RCPT,
DATA body and QUIT. Cancellation begins only after the peer receives RCPT;
the test requires the context cause and the peer's observed EOF. Fixture
cleanup is bounded and joined. IPv6 is available in the execution environment;
no case was skipped.
